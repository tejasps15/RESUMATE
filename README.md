#  RESUMATE – Resume & Career Intelligence Platform

**[🌐 Live Demo](https://resumate-jz6gkxphgyigepefxadqfm.streamlit.app/)**

## Overview

RESUMATE is an AI-powered resume and career intelligence platform developed using Python and Streamlit.

It helps users analyze their resumes, match their skills with suitable job roles, identify skill gaps, and discover relevant career opportunities.

## Features

- 📄 Resume upload and analysis
- 🔍 Resume content and skill analysis
- 💼 Job role matching
- 📊 Career dashboard
- 🎯 Job recommendations
- 💡 Skill-gap identification
- 📈 Career insights and reports
- 📝 Resume improvement suggestions

## Career Domains

The platform covers multiple career domains and provides suitable job roles based on the user's resume, skills, and career interests.

## Technologies Used

- Python
- Streamlit
- PyPDF
- python-docx
- Pandas
- Git & GitHub
